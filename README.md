# Joseph Xeno O. Banzon — Autobiography & Portfolio (CSIT 349)

Run locally:

    pip install -r requirements.txt
    streamlit run app.py

Deploy (bonus): push this folder to a public GitHub repo, then create the app at https://share.streamlit.io with `app.py` as the main file.

Things to edit in `app.py` (top of file):
- `SECTION` — your class section (shown in the top bar, sidebar and footer)
- `REPO` — per-project GitHub links (all point to your profile for now)
- `SKILLS` — the self-rated 0–100 numbers
- `CHAPTERS` — the autobiography text; make it sound like you

Photo: save a portrait as `assets/photo.jpg` (it replaces the stand-in avatar).
